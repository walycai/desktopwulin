# 农桑技能树（据《齐民要术》《天工开物》）v1

> 为「农隐」路线设计的种植 + 畜牧养殖技能树，节点取材于中国传统农学两大经典：
> 北魏·贾思勰《齐民要术》（耕作/选种/轮作/嫁接/养六畜/养鱼/酿造）、明·宋应星《天工开物》（乃粒·谷物水利/乃服·蚕桑/甘嗜·糖蜜/膏液·榨油）。
> 设计目标：让种田不是"多种点"，而是**用真实农学技法做有意义的决策**——节气、轮作、保墒、相畜、育种，每一项都是取舍。

---

## 结构总览
根节点 **务本**（农为邦本，解锁农桑路线）→ 三大分支：
- **甲 · 耕稼（种植）**
- **乙 · 畜牧（养殖）**
- **丙 · 制造（加工，两分支共享的产出转化）**
每分支按"阶"递进，高阶需前置 + 一定农桑声望/等级。

---

## 甲 · 耕稼（种植）｜取材《齐民要术》《天工开物·乃粒》

**一阶**
- **深耕**〔齐民要术·耕田〕｜"耕不厌熟"，深耕细作。｜田地基础产量 +。
- **保墒**〔齐民要术·耙耱〕｜耕后耙耱、保住墒情。｜作物耗水 −、抗旱 +（旱季少减产）。
- **选种**〔齐民要术·收种〕｜"取穗纯色者"，穗选留种。｜收获时有几率得到更优良种子。

**二阶**
- **溲种法**〔齐民要术·收种（骨汁粪种）〕｜以骨汁、附子拌种。｜出苗更快、抗病虫 +。（前置：选种）
- **顺天时**〔齐民要术·种谷 / 天工开物·乃粒〕｜依二十四节气物候下种。｜**应季种植大加成、反季大惩罚**——逼你按节气规划田亩。（前置：深耕）
- **粪壤**〔齐民要术·杂说（粪田）〕｜积粪肥田、"地力常新"。｜施肥系统：可提升地块"地力"，地力影响产量与品质。（前置：保墒）

**三阶**
- **轮作**〔齐民要术·大豆/种绿肥〕｜谷豆轮作、苕苜蓿作绿肥养地。｜**连作会地力衰减，需轮作或种绿肥恢复**——逼你规划种植顺序，而非年年同作物。（前置：粪壤）
- **水利**〔天工开物·乃粒（筒车/水车/陂塘）〕｜车水灌溉、修陂引渠。｜灌溉系统：旱季保收、水田解锁（稻）。（前置：顺天时）
- **嫁接**〔齐民要术·插梨/种枣桃〕｜果木嫁接。｜果树嫁接：培育更高产/更稀有的果木品种。（前置：溲种法）

**四阶（大成）**
- **育种**〔综合选种/嫁接〕｜定向选育。｜可**定向培育稀有、高价的良种/名品**（进商、文、医路线的高级原料）。（前置：轮作 + 嫁接）
- **五谷丰登**〔天工开物·乃粒〕｜大成。｜全作物产量、品质大幅提升；解锁"祥瑞/名产"事件。（前置：育种 + 水利）

## 乙 · 畜牧（养殖）｜取材《齐民要术·养六畜/养鱼》《天工开物·乃服/甘嗜》

**一阶**
- **相畜**〔齐民要术·相马/相牛〕｜相其形骨、择优而畜。｜挑选优质幼畜（初始资质更好）。
- **圈养**〔齐民要术·养猪/羊（栏厩）〕｜栏厩洁净、按时刍秣。｜牲畜健康 +、发病率 −。
- **牧草**〔齐民要术·种苜蓿〕｜种苜蓿/储刍豆为饲。｜饲料系统：自产饲料，降低养殖成本。

**二阶**
- **蚕桑**〔齐民要术·种桑养蚕 / 天工开物·乃服〕｜育蚕、缫丝。｜桑蚕系统：产丝——**高价纺织/文·商原料**。（前置：牧草，需桑田）
- **陂塘养鱼**〔齐民要术·养鱼（引陶朱公养鱼经）〕｜掘塘蓄水、以草养鱼。｜鱼塘系统（与"水利"联动更佳）。（前置：圈养）
- **养蜂**〔天工开物·甘嗜（蜂蜜/蜂蜡）〕｜割蜜取蜡。｜蜂蜜、蜂蜡产出——甜食/药材/文·商原料。（前置：相畜）

**三阶**
- **兽医**〔齐民要术·养牛马（相病/治疗）〕｜针药治畜、辨病防疫。｜治疗牲畜疾病、瘟疫防控，存活率大升。（前置：圈养 + 相畜）
- **孳乳**〔齐民要术·养六畜（孳生）〕｜择偶配种、繁育扩群。｜牲畜繁殖：扩大规模、遗传优良资质。（前置：牧草）

**四阶（大成）**
- **六畜兴旺**〔综合〕｜大成。｜全畜产出/繁殖/存活大幅提升；解锁名种（良马/名蚕等，接武·文·商）。（前置：兽医 + 孳乳）

## 丙 · 制造（加工）｜取材《天工开物·甘嗜/膏液/曲糵》《齐民要术·造酿》
（把种植/畜牧的原料转化成高价成品——决定"产出喂给哪条路线"）
- **酿造**〔齐民要术·造神曲并酒/作酱醋〕｜造曲酿酒、作酱作醋。｜谷物 → 酒/酱/醋（高价商品、宴请/情感事件用）。
- **制糖**〔天工开物·甘嗜〕｜甘蔗熬糖、米麦作饴。｜糖/饴（甜食、礼物、商品）。
- **榨油**〔天工开物·膏液〕｜油料压榨。｜食用油/灯油（日用、商品）。
- **乳酪脯腊**〔齐民要术·作酪/脯腊〕｜作乳酪、腊味脯。｜奶/肉 → 酪、腊味（耐存、高价）。
- **缫丝织造**〔天工开物·乃服〕｜缫丝、织丝麻棉。｜蚕丝 → 绸缎布帛（**直通文/商路线的高价成品与服饰外观**）。

## 树形前置关系（简）
```
务本(根)
 ├ 甲 深耕 → 顺天时 → 水利 ┐
 │  保墒 → 粪壤 → 轮作 ────┼→ 育种 → 五谷丰登
 │  选种 → 溲种法 → 嫁接 ──┘
 ├ 乙 相畜 → 养蜂 ; 相畜+圈养 → 兽医 ┐
 │  圈养 → 陂塘养鱼                  ├→ 六畜兴旺
 │  牧草 → 蚕桑 ; 牧草 → 孳乳 ───────┘
 └ 丙 制造（酿造/制糖/榨油/乳酪脯腊/缫丝织造，随甲乙产出解锁）
```

## 与其他系统/路线的联动
- **医**：药材种植（灵植）+ 溲种/育种 → 高阶药材；蜂蜜/乳酪入药膳。
- **商**：丝、糖、酒、油、腊味、名种 → 商路高价货源。
- **文**：绸缎/名酒/雅物 → 宴请、结缘、情报周旋的资源。
- **武/隐**：良马（六畜兴旺）供坐骑；田园自给支撑长期归隐。
- **声望**：农桑产出与里程碑（如首次五谷丰登、育出名种）按统一"声望"计入通关进度——保证农隐路线与其他路线通关时长同数量级。

## 决策深度（对应"数值是决策的输入、不是奖励"）
- **顺天时** → 逼你按节气排布种什么、何时种。
- **轮作/粪壤** → 连作衰减地力，逼你规划种植顺序与养地。
- **保墒/水利** → 看天吃饭，旱涝要主动应对。
- **相畜/育种/孳乳** → 资质与选育的取舍（像养成/抽卡但可控）。
- **制造** → 同一批原料，转化成哪种成品、喂给哪条路线，是持续的经营抉择。
所以农隐不是"多种点田"，而是一套需要动脑的传统农学经营。
