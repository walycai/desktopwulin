# 武侠生活经营游戏 · 角色设定

> 小镇全角色一览。目标：数量与多元度均高于同类生活模拟游戏，覆盖老中青幼、正邪灰、多样出身与武学。
> 每条：**姓名**（性别·年龄段·身份）｜表→里｜路线/武学关联｜钩子。〔结缘〕= 可攻略角色。

## 一、可结缘角色（14）
1. **沈青梧**〔结缘〕（女·青年·客栈孤女掌柜）｜开朗好客 → 为父复仇设局｜软剑｜温柔汤里藏杀机
2. **韦长歌**〔结缘〕（男·青年·落魄世家剑客）｜清冷孤高 → 灭门未雪｜剑法宗师·授剑功｜仁慈与冷酷并存
3. **林晚照**〔结缘〕（女·青年·药庐郎中）｜温婉济世 → 出身毒门｜毒/解毒/疗伤｜救人的手也能杀人
4. **裴见山**〔结缘〕（男·青年·破落少庄主）｜骄纵纨绔 → 被现实捶醒真心习武｜重兵·后期强援｜被打脸的少爷
5. **阿萤**〔结缘〕（女·青年·说书人/情报贩·孤儿）｜油嘴滑舌 → 谎话藏真心｜情报/黑市｜说谎者的真心
6. **白鹭**〔结缘〕（女·青年·卖艺舞伎·乐坊遗孤）｜柔媚周旋 → 忍辱寻兄｜音功/轻身｜笑靥背后的刀
7. **顾昀**〔结缘〕（男·青年·游方画师）｜洒脱不羁 → 因一幅画卷入灭门案｜画笔藏暗器｜画里有杀机
8. **齐砚**〔结缘〕（男·青年·落第书生/账房）｜迂腐书呆 → 胸有韬略图谋大事｜智谋·军师｜书生也有杀伐决断
9. **苗阿依**〔结缘〕（女·少女·南疆番邦少女）｜天真烂漫 → 背负部族灭亡与蛊术｜蛊/驯兽/毒｜甜笑养蛊
10. **云澈**〔结缘〕（男·青年·出走的道门弟子）｜清心寡欲 → 为仇为情道心动摇｜剑/内功/符箓｜六根未净的道士
11. **温窈**〔结缘〕（女·青年·避祸隐居的大家闺秀）｜知书达礼 → 掌门遗孤·身负重宝｜棋/暗器/内功｜柔弱贵女的杀招
12. **洪七**〔结缘〕（男·中年·豪爽退伍镖师）｜大碗喝酒 → 袍泽尽殁的战场创伤｜重兵/外功｜笑得越响心越空
13. **秦戍**〔结缘〕（男·中年·铸剑铺·退役镖师）｜豪爽糙汉 → 护镖惨败封刀｜装备打造/强化｜封刀的刀客
14. **苏怜**〔结缘·复杂线〕（女·青年·青楼花魁）｜风尘周旋 → 身不由己的细作｜情报/灰色｜赎身还是赴死

## 多元度覆盖
- **年龄**：孩童（小满/石头）· 少年（阿念/二郎）· 青年（多数结缘）· 中年（镖师/账房/屠户）· 老年（多位高人 + 神婆）。
- **正邪灰度**：正（秦捕头）· 邪（血刀/毒姑）· 灰（苏怜/钱敬/崔押司/货郎）。
- **出身**：本地市井 · 落魄贵族 · 退隐高手 · 江湖游侠 · 方外僧道 · 番邦异族 · 官军细作 · 复国旧臣。
- **武学**：剑/刀/重兵/拳/毒/暗器/内功/轻功/音功/符箓/蛊术/异域格斗/佛门/棍法。
- **路线覆盖**：武 · 医（林晚照/白眉/小满）· 商（阿萤/钱敬/钱通天）· 文（白鹭/顾昀/齐砚/宿老/文擂主）· 隐（田伯/孙麻子）。
- **边缘群体**：盲（瞎阿公）· 哑（阿念/黑巴）· 断臂（独臂陈）· 风尘（苏怜）· 乞丐（醉丐）——各具尊严与故事。

## 待定项
- 结缘人数与性别取向配比。
- 每人是否都配"心事件"弧线，还是分主次（核心结缘 + 次要镇民）。
- 反派/首领与升级挑战的节奏密度。
- 是否将每人展开为完整档案（外貌 / 日程 / 礼物喜好 / 心事件大纲）。
