# 《定风波》系统与数值设计要点（草案，供数值/系统规划）

> 定风波 = 武侠背景、带深度战斗的类星露谷生活经营 RPG。本文汇总与数值/系统直接相关的设计要点，供 @莱布尼茨 起数值。均为**可细化的草案，非锁死事实**；产品主次口径待 WalyCai 拍 A/B。

## 一、主次与三支柱
- **主系统 = 生活经营（种田/养殖/经营/社交，约 60–70%）**；**灵魂 = 人物剧情**；**差异化第二核心 = 武学战斗（约 30–40%，且是治中期枯燥的深度引擎）**。
- 核心循环：田园生产 → 准备江湖行动 → 战斗/调查/斡旋 → 带回资源·人物·矛盾 → 改变田庄与小镇。

## 二、六大生活技能（生产门类）
种地 · 养殖 · 钓鱼 · 草药医学 · 酿酒品酒 · 打铁炼器。（琴棋书画/音律=另一套"文艺技能"，不混入生产。）
- 每项按 10 级、五层组织：**识物 → 成事 → 精制 → 通变 → 济世**。
- 典籍气质参考：《齐民要术》《天工开物》（种/养/加工）、《本草纲目》（医）、《北山酒经》（酒）、《陶朱公养鱼经》（渔）。
- 种植/畜牧/加工的具体技法树见《定风波-农桑技能树》。

## 三、多路线进度均衡（保证通关时长同数量级）
- **共享进度货币「声望」**：所有路线（武/医/商/文/农隐）都产出声望；**每路线『声望/小时』校准到同一区间**（示例 12–18/时，硬夹 10–22）；主线里程碑按**累计声望**开闸。
- **数学保证**：单次动作声望 ∝ tier、单次耗时 ∝ tier 同步涨 → 声望/小时 ≈ 常数 K → 通关时长 = 总声望 / K ≈ 各路线相同。玩家差异来自效率（被夹在带内），不来自路线。
- **时长锚**：主线通关 ~60–90h，全收集长尾 150h+。
- **校准旋钮**：每路线声望/小时目标 / 每 tier 产出÷耗时比 / 软上限递减（防最速刷）/ 里程碑广度（多数闸吃任意路线声望→单路线可通关；少数关键闸要求混合来源→鼓励不强制多路线）。

## 四、货币-资源体系
```
【底层货币】时间(天/季) + 精力/内力(行动力)
   │投入
【六生活技能 + 武/医/商/文】劳作 → 【原料】粮·药·丝·矿·木石·猎获
   │增值加工链(酿酒/缫丝/铸器/制丹/熬糖) → 【高价成品】
   │卖 → 【金币】(通用流通) → 买 种苗/牲畜/建材/家具/装备/功法
【进度本位】声望 ← 里程碑/名声事件(风波已定/五谷丰登/名动江湖) → 推主线 → 结局
【专用货币】武学传承/门派贡献/江湖信誉(隔离特定内容, 防金币后期贬值)
【物料本位】木·石·铁(建造装饰需求恒在)
```
- 增值加工乘数 + 品质分级是财富核心引擎（别让金币只靠卖生货）。
- 反通胀：专用货币隔离内容 + 软上限递减。

## 五、生产 ↔ 武学 联动（种田流自带战斗力）
**原则**：生活塑造底盘，武学决定打法与上限。生活玩家不因种田变剑术宗师；纯武玩家也能战斗通关，但更缺钱/药/情报/非战解法。
- **生产被动练属性**（干什么练什么，跨进战斗）：种地→耐力/气血续航｜钓鱼→臂力/定力｜养马→移动骑乘｜养蜂毒虫→毒抗｜医学→伤势恢复/辨毒/经脉｜打铁→器物理解/自制兵器适性。
- **内功作桥梁**：内功管"精力消耗/恢复"，种田与战斗都要 → 农民流学内功为种田省精力，副产战斗续航。
- **平衡尺度**：生产+内功给"基础战斗力/续航/生还"，非"专业战力"；硬首领仍需专精武学或非战多解。机会成本/递减，不硬顶。

## 六、风波（阶段 Boss = 多解事件）
每场风波≥5 类解法：①武力 ②财富/生产 ③威望/人脉 ④知识/调查/证据 ⑤生产能力从根源化解。鼓励混合。**非战解法不能只是"威望≥50 按钮"**——同样要前期准备/材料/证据/支持者/代价，且不同解法留下不同后果（血仇/腐败/人情债/官府控制/无辜牵连/产业变化）。回报按声望均衡。

## 七、结局与长尾
- 主线收束触发多结局（叙事解决 + 声望里程碑触发，非硬时钟；择一承诺）：归田/守镇/问鼎/远游/同心/新门/无碑（词牌《定风波·X》）。
- **软结局 + 继续同存档**：世界延续并反映选择（避《大侠立志传》"称帝即终结"坑）。
- 通关后长尾（要有决策不只刷）：武学更高境界（超级首领/秘境=深度战斗 endgame）/ 攻略更多角色 / 全成就。

## 八、设计准绳
- 三段病=同一病（有意义决策密度衰减）：初期不累（爽点快/新手不裸奔）/ 中期不枯燥（升级挑战逼换 build，数值是决策输入非奖励）/ 后期不空（人物·家国·选择给非数值意义）。
- 星露谷留人真相：自我表达（田庄=画布）+ 归属感（NPC/小镇=家）+ 舒适精通；金币/成就是手段非目的。
- 居家建造装饰 = 次要金币回收 + 自我表达长尾（结构中期升满、装饰开放长尾）。
