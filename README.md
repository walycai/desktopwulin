# 桌面武林（desktop-wulin）

挂机经营 × 地宫 ARPG 双板块武侠游戏。**一套内核、多世界皮**的品牌(开罗模式)，首发武侠皮。
产品最终引擎 Godot 4；当前为 H5 操作验证原型（所见即所得、零安装预览），数据/玩法可平移。

> 独立项目，与《长安回望》完全隔离。

## 当前阶段：室内家园 + 精细摆放原型 v0.1
- 室内场景，精细网格地板(每格 20px)，后墙放壁挂。
- 仓库包按类别(床/功能/椅/桌/壁挂/装饰)点选 → 房间内吸附摆放；可拖动、按 R 旋转、右键收回。
- 功能件：
  - 床(普通/高级)：主角点击→走过去睡觉，回血 + 解负面(中毒/虚弱)，两档速率不同。
  - 打坐台：固定不可拖；主角点击→走过去打坐，缓慢提升内功等级。
- 主角：平时在房间随机溜达；只有床和打坐台可主动点击；点空白处结束当前行为。
- 顶栏调试按钮：施加中毒/虚弱/受伤，便于看床的恢复效果。
- 自动存档(localStorage)。

## 美术接入（@吴冠中，像素风）
- 家具/物品：透明底 PNG，放 `assets/furniture/<category>/<asset_id>.png`，引擎自动用真图，缺图用占位。
  - category = bed / func / chair / table / wallhang / decor
- 主角动画：`assets/characters/protagonist/<anim>_<direction>.png`（anim = idle/walk/sleep/meditate）。
- 网格基准每格 20px；单件像素 = 占格数 × 20。功能件占格：普通床 12×24、高级床 16×28、打坐台 12×12(固定)。
- 占格(footprint)在 `src/game.js` 顶部 `CATALOG` 调；真图定稿后对齐微调。

## 运行
