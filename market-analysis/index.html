大盘在涨，但竞争更凶：8 年前首发能到 500 CCU 的位置，现在只有约 100（"饱和拖累"）。成功率反而升到 3%，说明做得更准的人变多了，不是钱变多了。中位游戏 2025 年毛收入仅 $249 —— 这是理解一切商业决策的起点。

🔥 正在起飞 / 上升

  • 联机社交 / 搜刮恐怖（co-op extraction horror） —— 本轮最强爆点。Lethal Company → R.E.P.O.（2 月首发即屠榜）→ PEAK（销量破 1000 万）。低多边形 + 物理 / 近距语音 + 极强可直播性。co-op 品类 2025 上半年 $4B+。
  • Roguelike 卡牌构筑 / 单机制 roguelike —— Balatro 余震，Monster Train 2（$3.8M）。"再来一局" + 可直播。
  • 叙事 + FMV（真人影像） —— 2025 叙事类 51 款成功登顶品类第一，其中 19 款 FMV、多为中国团队做英文本地化，正在养成西方受众。
  • 系统 / 经营模拟 —— Schedule I（毒枭经营黑马）；管理类稳居前十。
  • Idle / 放置 —— 27 款成功，开发便宜、ROI 高，被严重低估。
  • Anime RPG / JRPG 复兴；农耕（成功率 8.3% 很高，但已拥挤，必须带钩子）。

❄️ 饱和 / 退潮（慎入）

吸血鬼幸存者-like、boomer shooter、通用魂-like、类银河恶魔城、2D 平台跳跃（成功率 0.18%）、点击冒险（0.18%）、VR（0.27%）、通用像素农场克隆、纯步行模拟。

02判断风口的工具与方法论

数据源工具

  • GameDiscoverCo（Simon Carless） —— PC/主机趋势的金标准 newsletter，追踪未发售游戏的愿望单积累、Next Fest 转化、品类成功率。
  • VG Insights / Gamalytic —— 按 tag / 品类估算营收、愿望单、销量。
  • SteamDB（实时 CCU / 关注数 / 价格史）、games-stats / Steam Marketing Tool（按 tag 出中位营收表）。
  • Steam 官方：畅销榜 / 最多愿望单榜 / Next Fest（试玩节）—— demo 的中位 CCU 是最强的发售前信号。
  • Twitch / YouTube 观看时长、Google Trends、Reddit / Discord 社群增速 —— 判断可直播性 / 病毒性。

五个核心框架

1. 供需缺口（顺流而游 swim with the current）

核心指标 = 品类成功率（该 tag 里冲到 1000+ 好评的比例）。高需求（玩家多、单款营收高）+ 低供给（游戏少）= 机会。

→ 判断风口最硬的一招。参考：开放世界生存建造 20.8% / 农耕 8.3% / Roguelike 卡牌 5.1%。

2. 饱和度 / 竞争指数

同一 tag 游戏数逐年涨、但中位 CCU 在跌 = 已饱和。

→ 避开红海（吸血鬼幸存者-like、2D 平台、魂-like）。

3. 异类 / 爆款侦测（outlier detection）

盯住远超其 tag 平均的那一款 —— 它就是新细分品类的种子。爆款出现后"快速跟进窗口"约 6–18 个月。GameDiscoverCo 靠未发售游戏的愿望单积累速度提前抓。

→ 种子案例：Balatro、Lethal Company、PEAK。

4. 幂律现实（hit-driven）

中位游戏只赚 $249，收益极度长尾、赢家通吃。

→ 为前 3% 的异类设计，不为中位数设计。品类 / 赛道选择的杠杆远大于"多努力一点"。

5. 愿望单基准线（发售前体温计）

7–10k 才有曝光、25–50k 甜区、100k+ 爆款区；首周愿望单转化中位约 10.5%（生存 / 模拟 / 成人更高）。

→ store page 越早建越好、持续喂愿望单。

元方法：永远交叉验证多个先行指标（愿望单 + Next Fest CCU + 直播时长 + 社群增速），别信单一数字；抓时机窗口。

03行业共识（制作侧 + 商业侧）

制作 / 设计侧

① 玩法循环 > 表面精致

营收由玩法循环与沉浸感驱动，不是画面精度。机制：留存靠"再来一次"的循环张力，口碑 / 直播靠机制惊喜；画质只影响点进来的第一下。

→ 预算优先砸核心循环，别砸美术军备竞赛。

② 熟悉的核心 + 一个尖锐的新扭曲

纯原创极难卖（无搜索需求、教育成本高），纯克隆无差异化。案例：Balatro=扑克×roguelike；吸血鬼幸存者=成长×自动战斗；Stardew=牧场物语×开放自由。

→ 站在成熟品类肩上，只押一个锋利的差异化钩子。

③ 一句话电梯陈述 + capsule 点击率

玩家在 Steam 上约 0.5 秒决定点不点。机制：货架经济，capsule / 短视频 CTR 是漏斗第一环。

→ 立项时就要能一句话说清"你是谁、扭曲在哪"。

④ 第一个"啊哈时刻"要早

Demo / Next Fest 转化主要由"前几分钟有没有交付核心乐趣"决定。

→ 核心乐趣前置，别让玩家爬 30 分钟教程。

⑤ 可直播 / 可分享性 = 免费流量引擎（已是设计轴）

"好不好看别人玩"现在是设计维度。Lethal Company / co-op / 涌现名场面靠这个病毒式增长。

→ 即使单机，也要主动设计"名局 / 名场面 / 可截图时刻"。

⑥ 系统深度来自涌现，不是堆内容

少量规则相互作用产生海量策略（国际象棋 vs 线性关卡）。堆内容是线性成本无底洞、且会被玩穿。

→ 把深度压在"系统交互"上。

⑦ 难度可调 + 失败低惩罚

现代玩家宽容度设计成主流：快速重试、软失败、可跳过。

→ 提高留存与"再试一次"。

⑧ 范围控制 = 头号存活技能

小团队最大死因是做不完 / 做太久烧光钱。范围指数级膨胀、资金线性消耗。

→ 先做垂直切片跑通核心循环，验证了再扩。

商业 / 价值侧

⑨ 幂律 / 命中驱动市场（最重要的商业事实）

中位游戏 $249，收益极度长尾。

→ 要么做成前 3% 的异类，要么别做；赛道选择 > 努力。

⑩ 供需缺口（顺流而游）

选高需求、低供给的赛道，用品类成功率当硬指标。

→ 别进红海，找蓝海缺口。

⑪ 愿望单 = 命脉 + 算法飞轮燃料

首发日愿望单转化直接喂 Steam"热门新品 / 首发榜"算法，进榜 = 自然流量爆发。马太效应：首发势能（愿望单 + 首日销量 + 好评速度）决定曝光，曝光又决定销量。

→ 尽早建 page、持续喂、首发火力集中。

⑫ 长尾 / catalog 复利 = 真正的 LTV

买断游戏终身价值主要来自长尾（多年折扣、捆绑、新玩家），不是首周。"没有 catalog 收入的发行商 risky AF"。

→ 做"耐卖"的游戏（高可重玩、常更新）。

⑬ 社区 / 口碑 = 独游唯一买得起的营销

Discord / Reddit / 创作者复利，成本近零、可累积。

→ 从第一天养社群。

⑭ 本地化 ROI 被低估

中文 / 俄语等本地化常有超额回报，小成本打开整块市场。

→ 华语团队做武侠：中文是基本盘，英文 / 其他是增量放大器。

⑮ 定价与折扣纪律

首发别急打折（伤愿望单信任），但必须参与季度大促拿可见度。

04用这套方法论分析《定风波》

定风波 = 武侠背景、带深度战斗系统的"类星露谷"生活模拟经营 RPG。三支柱：① 武学 build-craft 战斗（差异化脊柱）② 人物剧情（灵魂）③ 生活经营（底色）。数值是解题的输入，不是奖励。

1. 供需缺口 → ✅ 强（我们最大的结构性机会）

需求侧：生活模拟 / 经营是 Steam 长虹品类，需求盘大、稳。
供给侧空白：绝大多数生活模拟的战斗是"两张皮"、很浅。"带真正 build-craft 战斗深度的生活模拟"几乎没有供给。

结论：高需求 × 低供给的清晰缺口 —— 这就是我们顺流的赛道。

⚠️ 生活模拟外壳本身拥挤，护城河必须是战斗深度这个钩子，不能退化成"武侠皮的星露谷克隆"。

2. 熟悉核心 + 尖锐扭曲 → ✅ 完美契合范式

熟悉核心 = 星露谷式生活经营循环（零教育成本、capsule 好讲）；尖锐扭曲 = 武学 build-craft 战斗 + 江湖多路线 / 多结局抉择。

一句话陈述："一个你能真正钻研武学 build 的武侠星露谷。"

3. 时机（顺风与逆风）

顺风：JRPG / 叙事复兴、中国团队叙事在西方起量、东方 / 武侠题材全球好奇心。
逆风：武侠对西方有认知门槛。破法：用普世情感降门槛（自由、师徒、快意恩仇、正义 vs 生存）+ 强视觉，别依赖玩家懂武侠。

4. 可直播性 → ⚠️ 中，需主动补

单机生活模拟天然直播性中等。要主动设计"名场面"当燃料：靠 build 解题翻盘的 boss / 踢馆战、改变结局的江湖抉择、种田流硬刚仇家。战斗 build-craft 恰是最出"名局"的部分。

5. 幂律含义 → 差异化就是冲前 3% 的杠杆

做成"中位种田克隆"= 白做。战斗深度 + sim 数值执行力（我们相对创意的结构性优势）正是把我们推向异类的杠杆 —— 执行力护城河比创意更难被抄。

6. 范围控制 → 🔴 头号商业风险

三支柱 × 五路线（武 / 医 / 商 / 文 / 农隐）× 多结局 = scope 巨大。做不完 / 做太久，是最可能杀死这个项目的东西。

解法（两条都要用）：
• agent 工作室的高产能（美术 / 数值 / 文案并行）—— 我们相对人类小团队的真实优势。
• 垂直切片先行：先把"生产 ↔ 属性 ↔ 内功 ↔ 战斗"共享底盘的最小可玩闭环 + 一条主线路线跑通，验证核心乐趣与留存，再逐路线 / 结局扩。

7. 愿望单 / 冷启动 → 买断单机的命脉

武侠 + 战斗深度 + 精美像素有很强的 capsule 钩子潜力。行动：尽早建 store page、放战斗 build 解题 + 江湖抉择的动图、认真打 Next Fest demo（前 5 分钟交付一次"啊哈"）。

8. 受众 / 本地化 → 基本盘 + 放大器

中文母市场（武侠零教育成本）= 基本盘；英文 / 其他本地化 = 增量放大器。两头都要。

机会评分（对照"下一个爆款"清单）

维度定风波说明
成熟循环 + 新扭曲✅ 强星露谷循环 × 战斗 build 扭曲
踩供需缺口✅ 强深战斗 × 生活模拟 = 空白
近期需求验证但未泛滥✅ 强生活模拟长虹、叙事 / 东方顺风、深战斗生活模拟没人填
可直播 / 可病毒⚠️ 中需主动设计战斗 / 抉择名场面
小团队可达质量门槛⚠️ 风险scope 大；靠 agent 产能 + 垂直切片化解

一句话结论：定风波踩在一个真实的高需求低供给缺口上，扭曲够尖、执行力是我们的护城河；最大且唯一的致命风险是范围失控 —— 赢面取决于我们能不能用"垂直切片先跑通核心闭环"的纪律把它做完、做出高光。
