# 《定风波》生产原型 v0.1 — 事件字典（三方共用单一来源）

> 由 @雅各布 的状态机产出，是工程/数值/文本共用的**唯一事件 key 来源**。
> - @古龙 在同一 key 下挂：事件标题、引导句、"下一步动作"文本。
> - @莱布尼茨 在同一 key 下挂：产量 Y、售价、解锁门槛、里程碑声望。
> 后期换美术/调数值/补文本都不改 key，不做映射返工。

## 事件接口（每个事件都带这 5 个字段）
`key` · `首次触发(bool)` · `当前阶段` · `产物与数量` · `新解锁项` · `下一步动作`

（v0.1 三套系统开局全开放，暂无解锁门槛，`新解锁项` 多为空，槽位保留给"卖够钱解锁新作物/新配方/新畜种"等后续 gating。）

## 稳定枚举（v0.1）
| key | 类型 | 触发时机 | 当前阶段 | 产物与数量 | 新解锁项 | 下一步动作 |
|---|---|---|---|---|---|---|
| `game_start` | 一次 | 进入游戏 | - | 起始背包(麦种×3/稻种×3/金币50) | - | 开垦农田 |
| `first_till` | 首次+复发 | 空地→开垦 | 已耕 | - | - | 选种子播种 |
| `first_plant` | 首次+复发 | 已耕→播种 | 阶段 0/N | 作物幼苗 | - | 推进一步让作物生长 |
| `crop_ripe` | 状态·复发 | 作物长到满阶段 | 成熟 | 作物 可收获 | - | 点该地块收获 |
| `first_harvest` | 首次+复发 | 收获成熟作物 | 成熟 | 作物 ×N | - | 拿去酿造增值 / 卖出 |
| `animal_ready` | 状态·复发 | 畜产计数满 | 就绪 | 畜产 待收 | - | 点畜栏收集 |
| `first_egg` | 首次+复发 | 收集畜产 | 畜栏产出 | 鸡蛋 ×N | - | 攒着卖 / 作原料 |
| `first_brew_load` | 首次+复发 | 空缸投料 | 发酵 0/N | 原料→成品(酿造中) | - | 推进一步等出窖 |
| `brew_ready` | 状态·复发 | 发酵计数满 | 出窖 | 成品 待取 | - | 点酒缸取酒 |
| `first_brew_done` | 首次+复发 | 取酒 | 出窖 | 成品 ×N | - | 卖出(体现加工乘数) |
| `first_sale` | 首次+复发 | 卖出作物/成品 | 交易完成 | +金币(明细) | - | 金币买种苗/建材/家具 |

- **类型说明**：`首次+复发`＝每次都发事件，`首次触发`字段区分是不是第一次（古龙可只给首次配一段特写文本，之后走简短复发文本）；`状态·复发`＝纯就绪提醒。
- 事件同时 `print("[里程碑] key=... first=... title=... stage=... product=... next=...")`，便于埋点/抓流。

## 给 @莱布尼茨 的三链数据握手（v0.1 实测结构 + 占位值）
> 占位值是我为跑通逻辑随手定的、**未平衡**，等你按"净收益率收敛"反推。结构是稳的。

| 链 | ①原料/投入 | ②一循环(产量Y + 步骤数) | ③加工输入输出比·乘数 | ④品质Q | ⑤售价 |
|---|---|---|---|---|---|
| 农耕 | 麦种/稻种(起始给，买价待定) | 小麦/稻谷 ×1；播种1 + 推进3 + 收获1 | 无(农耕是基础链) | v0.1无分级(占位) | 小麦8 / 稻谷6 |
| 养殖 | 鸡(买价待定；饲料吃农耕，待接) | 鸡蛋 ×1；推进3 + 收集1 | 无 | 无 | 鸡蛋10 |
| 酿酒 | 小麦/稻谷(自产或买) | 酒 ×1；投料1 + 推进3 + 取酒1 | 1作物→1酒；麦酒34/小麦8=**4.25×**，米酒30/稻谷6=**5.0×** | 无 | 麦酒34 / 米酒30 |

- 你的"净收益率收敛"正好能修我这套占位（现在酿酒乘数 4-5× 明显没算前置投入，等你拉平）。
- 里程碑声望：挂上表 key（`first_harvest`/`first_brew_done`/`first_sale` 等即进度锚），"新解锁项"槽＝你配解锁门槛处。

## v0.2 更新（走格实时玩法：主角走位 + 实时生长，弃「推进一步」）
交互从"点按钮推进"改成"主角走田里用工具侍弄、作物按真实秒生长"，引导语义随之变，事件字典同步：

**改动（next_action 语义变）：**
- `first_plant` 下一步：~~推进作物生长~~ → **用水壶为地块浇水**（浇了才开始长）。
- `first_brew_load` 下一步：~~推进酿制~~ → **酒液成熟后回来取酒**（无推进按钮，实时90秒出窖）。

**新增两个首次教学 key：**
- `first_water`：浇水后作物才开始生长（明确"浇水=启动生长"）。
- `first_fertilize`：施肥可选，只负责加速（不浇水施肥无效）。

**v0.2 实际触发的 key 集（状态机当前来源）：**
`first_till · first_plant · first_water · first_fertilize · first_harvest · first_egg · first_brew_done`
（各以 toast 首次教学；古龙在 event_copy.json 同 key 补 title/first_text。）

**v0.2 暂缓的 v0.1 key（保留、机制回归时再启用）：**
- `crop_ripe` / `animal_ready` / `brew_ready`：就绪现在靠地块/站点上的**倒计时+✔视觉**表达，不再发 toast。
- `first_sale` / `game_start`：v0.2 暂无"卖出"动作与开场事件（卖出待加 market 站点；开场引导待定）。

> 变量契约不变：`{stage}/{output}/{unlock}` 仍按 common_lines、非空才显示；古龙只在同一份 event_copy.json 迭代，不另开映射。
